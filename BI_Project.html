Siemens Professional Project

MODEL-BASED DEFINITION BUSINESS INTELLIGENCE TRACKING

Engineering advanced business intelligence reporting, event tracking, and analytics pipelines tailored for Model-Based Definition (MBD) workflows. This project focused on auditing SAN server architectures, analyzing core event types, and developing extraction methodologies for enterprise engineering metadata.

PROJECT OVERVIEW & OBJECTIVE

As part of the MBD Apps team at Siemens Digital Industries Software, this project was aimed at establishing event tracking, and business intelligence capabilities across complex Model-Based Definition workflows. The primary goal was to audit existing server data structures, uncover metadata gaps, and implement scalable query event properties for enhanced engineering analytics.

KEY TECHNICAL CONTRIBUTIONS

  • SAN Server Analytics: Audited 70+ properties across PMI and MBD event to identify event tracking gaps.
  • Event Tracking Implementation: leveraged the existing enterprise infrastructure to plug in missing event tracking capabilities.
