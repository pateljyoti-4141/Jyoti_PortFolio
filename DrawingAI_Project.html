Siemens Professional Project

CAD Drawing Automation

Developing AI-driven drawing automation tools, leveraging machine learning models to predict optimal views for proper documentation and drafting of model parts.

PROJECT OVERVIEW & OBJECTIVE

As part of the Siemens Design Center team, this project focused on advancing automatic drawing generation and verification workflows through intelligent AI tooling. The core objective was integrating machine learning models to predict optimal part views for accurate technical documentation, minimizing manual drafting overhead, and accelerating the design-to-production lifecycle.

KEY CONTRIBUTIONS & FEATURES

  • ML-Driven View Prediction: Integrated machine learning models ONNX Runtime wrapper for inferencing to predict ideal orthographic required for proper engineering documentation on the basis of 3D model geometries.
  • UI for execution: Designed and implemented a user-friendly interface for executing the AI-driven drawing automation features.
  • Unit Testing: Implemented comprehensive unit tests to ensure the reliability and performance of the AI-driven drawing automation features.

TOOLS & TECHNOLOGIES USED

  • Machine Learning Model Integration
  • Wrapper or Adapter Design Pattern
  • ONNX Runtime Inferencing
  • Unit Testing & Debugging
